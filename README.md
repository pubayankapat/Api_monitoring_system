This is software responsible for monitoring api endpoints and sending notifications when they are down. It is built using Node.js and Express.js, and uses MongoDB for storing data. It will analyse the response time of the endpoints and send notifications if the response time exceeds a certain threshold. It also has a dashboard for viewing the status of the endpoints and the notifications sent.
-----------------------------------------------------------------------------------------------------------------------------
Further scope of improvement includes an ai that automatically detect fault and try to fix it. It will also have a feature to automatically scale the infrastructure based on the load. Additionally, it will have a feature to automatically update the endpoints and the notifications based on the latest trends and best practices.
